# LaunchDesk — Video Demo Script (2–3 menit)

> Upload ke YouTube **Public** · Daftar per adegan dengan narasi (voiceover).
> Semua angka di bawah adalah **hasil live terverifikasi** (Kamis 13 Agu 2026).

## Ringkasan alur

1. Buka `https://launchdesk.pages.dev`
2. Paste link Play Store/App Store (contoh: Duolingo)
3. **Analyze** → skor C/66 + breakdown 28 aturan
4. **Revise** → `Real AI` → skor naik ke B/77 (dari C/66)
5. **Promo kit** → deep link, QR, smart banner, publish payload

**Visual:** Tampilan landing page LaunchDesk (hero + tombol "Analyze my app").

**Narasi (EN):**
> "Every indie developer faces the same Day-1 wall: they publish an app, and nobody
> finds it. LaunchDesk fixes that. Paste your App Store or Play Store link, and it
> grades your listing with 28 deterministic ASO rules, rewrites it with real AI, and
> generates a verified promo kit. Let's walk through the whole flow."

## Adegan 2 — Analyze (0:20–0:50, ±30 detik)

**Visual:** Paste contoh link, klik tombol, loading, tampil hasil skor.

```
https://play.google.com/store/apps/details?id=com.duolingo
```

**Hasil live:** skor **C/66** — 28 aturan dievaluasi, beberapa gagal
(title length, keyword, description CTA, dsb).

**Narasi:**
> "I'll use a real app — Duolingo. LaunchDesk fetches the actual listing from the
> store, no mock data. The quality gate scores it against 28 rules: title, subtitle,

> the top five fixes to prioritize, and a 30/60/90 launch roadmap."
